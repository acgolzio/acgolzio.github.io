Atividade 5 · Modelos de linguagem

Prever a próxima palavra contando: N-gramas, suavização e perplexidade

Contexto

Um modelo de linguagem atribui probabilidade a sequências de palavras e prevê a próxima palavra dado o contexto. O modelo de N-gramas usa a hipótese de Markov: só as N − 1 palavras anteriores importam. As probabilidades vêm de contagens (estimativa de máxima verossimilhança); a suavização evita probabilidade zero para sequências não vistas; a perplexidade mede quão bem o modelo prevê um texto novo (menor é melhor) (SHANNON, 1948; JURAFSKY; MARTIN, 2024, cap. 3).

Para discutir

  1. Shannon (1948) já gerava "texto" com N-gramas de letras e palavras. Quanto maior o N, mais "parecido com língua" fica o texto, mas mais ele copia o corpus. Fluência é o mesmo que entendimento?
  2. Com MLE, uma frase com um único bigrama nunca visto recebe probabilidade zero: o modelo declara impossível o que só é novo. Que pressupostos sobre o mundo a suavização introduz?
