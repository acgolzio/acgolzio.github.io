Atividade 2 · Tokenização

Tokens, IDs e embeddings: como uma frase entra num Transformer

Contexto

Um token pode ser uma palavra, uma subpalavra ou um caractere. Os Transformers costumam usar subpalavras (BPE, WordPiece, SentencePiece) para lidar com palavras raras e desconhecidas. Cada token vira um número inteiro (ID) num vocabulário e cada ID seleciona uma linha de uma matriz de embeddings de tamanho V × d (SENNRICH; HADDOW; BIRCH, 2016).
